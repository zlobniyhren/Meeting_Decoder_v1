# Автоматический обработчик видео встреч

Этот скрипт автоматически отслеживает папку с видео файлами, извлекает из них аудио и транскрибирует речь в текст с помощью Whisper.

## Как использовать

### 1. Установка зависимостей

```bash
# Установите ffmpeg (если еще не установлен)
brew install ffmpeg

# Установите fswatch для мгновенного отслеживания файлов (опционально)
brew install fswatch
```

### 2. Запуск скрипта

```bash
# Перейдите в папку проекта
cd "/Users/evgenijharitonenko/Вайбкодинг/Meeting decoder/CascadeProjects/windsurf-project"

# Сделайте скрипт исполняемым
chmod +x video_processor.sh

# Запустите скрипт
./video_processor.sh
```

### 3. Использование

1. Запустите скрипт
2. Поместите видео файл в папку `video_input/`
3. Скрипт автоматически:
   - Извлечет аудио в папку `audio_output/`
   - Распознает речь с помощью Whisper
   - Сохранит текст в папку `text_output/`
   - Переместит обработанное видео в `video_input/processed/`

## Структура папок

```
windsurf-project/
├── video_processor.sh          # Основной скрипт
├── video_input/               # Папка для входных видео
│   └── processed/             # Обработанные видео
├── audio_output/              # Извлеченное аудио
├── text_output/               # Транскрибированный текст
└── README.md                  # Этот файл
```

## Поддерживаемые форматы видео

- MP4
- AVI
- MOV
- MKV
- FLV
- WMV

## Настройки

В скрипте можно изменить следующие параметры:

- `WHISPER_PATH` - путь к исполняемому файлу whisper-cli
- `VIDEO_INPUT_DIR` - папка для входных видео
- `AUDIO_OUTPUT_DIR` - папка для извлеченного аудио
- `TEXT_OUTPUT_DIR` - папка для текстовых файлов

## Особенности

- **Автоматическое отслеживание**: Скрипт следит за папкой и обрабатывает новые файлы мгновенно (если установлен fswatch)
- **Предотвращение дублирования**: Уже обработанные файлы пропускаются
- **Статистика обработки**: Показывает размер файлов и длительность аудио
- **Организация файлов**: Обработанные видео перемещаются в отдельную папку

## Остановка скрипта

Нажмите `Ctrl+C` в терминале для остановки скрипта.

## Troubleshooting

### Если whisper не находит модель

Убедитесь что модель `ggml-base.bin` находится в папке `/Users/evgenijharitonenko/Вайбкодинг/Whisper/models/`

### Если ffmpeg не найден

Установите ffmpeg: `brew install ffmpeg`

### Если нет мгновенной обработки

Установите fswatch: `brew install fswatch`
